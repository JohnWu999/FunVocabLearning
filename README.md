# 互动单词学习项目 📖

> **Fun Vocabulary Learning** — 专为 Michelle 打造的英语词汇互动学习项目

## 🎯 项目简介

本项目基于 **Caesar's English II** 经典词汇教材，整合拉丁词根、文学引用与互动练习题，帮助学习者系统掌握高阶英语词汇。
